# 桌面快捷方式与图标

这个目录放的是「从桌面直接打开木火账房」所需的东西。
它们不属于应用运行时，删掉不影响系统本身。

## 文件

| 文件 | 作用 |
| --- | --- |
| `Install-Shortcut.ps1` | 在桌面创建/修复「木火账房」快捷方式（**换机器或挪了仓库之后跑一次这个**） |
| `Open-MuhuoLedger.ps1` | 快捷方式实际执行的脚本：确保服务在跑 → 等就绪 → 打开浏览器 |
| `muhuo-ledger.ico` | 多尺寸图标（16/24/32/48/64/128/256） |
| `icon.svg` | 图标源文件，详细版（用于 ≥32px） |
| `icon-small.svg` | 图标源文件，小尺寸版（用于 16/24px） |

## 为什么需要启动器，而不是快捷方式直接指向网址

快捷方式若直接写 `http://localhost:8080`，在服务没起来时点开就是一个
「无法访问此网站」的死页面，用户不知道该怎么办。启动器会先把服务拉起来。

## 图标为什么有两版

48 网格缩到 16px 时，详细版的三片叶子宽度不足 1 个像素，只会糊成一团；
12px 的圆角也会把深色底吃掉大半。所以小尺寸单独画一版：只保留
**深色方章（土）＋ 粗树干（木）＋ 贴地一簇火（火）**，并把颜色提到
色板里更浅的档位（wood-300/400、fire-400）以提高对比度 —— 色相不变，
只是让它在任务栏里认得出。

图形与 `apps/web/src/components/AppLogo.vue` 同构。**改配色时要一起改三处**：
`apps/web/src/styles/theme.css`、`AppLogo.vue`、这里两个 SVG。

## 重新生成 .ico

SVG 不能直接当图标用，需要栅格化成多尺寸 ICO。本仓库不引入这个构建依赖
（只在需要改图标时用一次），在临时目录里装工具即可：

```powershell
mkdir $env:TEMP\bk-icon; cd $env:TEMP\bk-icon
npm install @resvg/resvg-js png-to-ico
```

然后按 `icon.svg`（≥32px）与 `icon-small.svg`（≤24px）分别渲染并打包。
也可以直接用任意图标工具（如 ImageMagick、icofx）打开这两个 SVG 另存为 .ico。

## 已知限制

- 快捷方式里存的是**绝对路径**。仓库移动后它会变成死链接 ——
  重新运行 `Install-Shortcut.ps1` 即可修好。
- 启动器假定 Docker Desktop 已安装。未安装时会弹窗说明，不会静默失败。
- 启动器只拉起 Docker 那套部署（`:8080`）。开发用的 Vite（`:5173`）
  需要手动起 —— 它会产生常驻的 node 进程，不适合由快捷方式隐式拉起。
