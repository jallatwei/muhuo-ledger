# 八字推算：口径与依据

> 这份文档记录**推算口径**及其文献依据。
> 之所以要单独成文：八字推算里绝大多数步骤是确定的（干支表、儒略日、五鼠遁），
> 但**子时的日界**有两种说法，且都能找到出处。不写清楚口径，
> 别人拿另一派排盘来对照就会以为算错了。
>
> 配色方案的依据见 `主题配色-八字喜用.md`。

## 一、确定无疑的部分（无流派争议）

| 项 | 口径 | 依据 |
|---|---|---|
| 年柱分界 | **立春**，且以**时刻**为界而非日期 | 八字以节气立年，非以正月初一 |
| 月柱分界 | **十二节**（立春/惊蛰/清明…大雪/小寒） | 月建以节为界，非以农历初一 |
| 日柱 | 儒略日推算 | JDN 连续，不受闰年与月长影响 |
| 时柱 | **五鼠遁**：甲己还加甲、乙庚丙作初、丙辛从戊起、丁壬庚子居、戊癸何方发、壬子是真途 | 时干由日干推 |
| 真太阳时 | 经度时差 + 均时差 + 夏令时 | 天文定义，非命理约定 |

### 真太阳时的三步修正

```
真太阳时 = 钟表时间 + 经度时差 + 均时差 − 夏令时补偿

① 经度时差 = (出生地经度 − 120) × 4 分钟
   每偏离标准经线 1 度差 4 分钟。吉林市 126.56°E → 早 26.2 分钟
② 均时差：地球轨道为椭圆且黄赤交角存在，一年内 ±15 分钟摆动
   1 月下旬约 −12.3 分钟
③ 夏令时：中国 1986-1991 年夏季实行过，那段时间钟表时间要减 1 小时
```

第 ③ 条容易被忽略：1986-1991 年出生的人，若出生证明上的时间未标注夏令时，
实际标准时可能比记录的**早 1 小时**，足以跨过一个时辰。

第 ① 条的量级随地点变化极大，值得记住几个极端值：

| 出生地 | 经度 | 经度时差 |
|---|---|---|
| 乌鲁木齐 | 87.62°E | **−130 分**（约 −2 小时 10 分） |
| 喀什 | 75.99°E | **−176 分**（近 −3 小时） |
| 北京 | 116.41°E | −14 分 |
| 上海 | 121.47°E | +6 分 |
| 长春 | 125.32°E | +21 分 |
| 吉林 | 126.56°E | +26 分 |
| 哈尔滨 | 126.63°E | +27 分 |

在西部，不做经度修正几乎必然把时辰算错一到两个。

## 二、子时日界：两种口径与各自出处

这是唯一有争议的地方。争议点是：**日的分界在子初（23:00）还是子正（00:00）？**

### 口径 A：日在子正（00:00），子时分早晚

**主张**：日的分界是子时中点（00:00）。23:00-23:59 为「晚子时」，
仍属**当日**；00:00-00:59 为「早子时」，属**次日**。
日柱在 00:00 换，不在 23:00 换。

> ★ 注意一个容易搞混的点：口径 A 下**时干只有一个**。
> 既然 23:00-23:59 仍属当日，五鼠遁就用**当日**日干推 ——
> 因此这例（真太阳时 23:28，日柱丙寅）的时柱是 **戊子**。
> 有些黄历会把 23:00-23:59 的时干标成「次日日干推出的子时干」，
> 那是把口径 B 的算法混进了口径 A 的日界里，两派都不认。

**文献依据**：

- 《新唐书·历表》：「古历分日，**起于子半**。」
  子半即子时之中点，也就是 00:00。
- 《渊海子平·论十二生肖》：
  「如子虽属阳，**上四刻乃昨夜之阴，下四刻今日之阳**。
  鼠前足四爪象阴，后足五爪象阳故也。」
- 《星平大成》：
  「若子时，则上半时在夜半前，属昨日。下半时在夜半后，属今日。
  ……子正者，今日之早，非昨日之晚也。夜子者，今日之夜，非今日之早也。」

### 口径 B：日在子初（23:00），子时不换日

**主张**：子时是一个完整的「气」，不应再分早晚。
日柱在 23:00 就进次日，时干用**次日**日干推。

**文献依据**：

- 韦千里《千里命稿》：
  「俗有所谓『早子时夜子时』之分别者……此论历法则或可，**论命则万万不可**。
  考历书之称夜子时，盖表明节气之交换，在夜子时之初（即十二点钟之前）也，
  故只有夜子初几刻几分，从未言及夜子正几刻几分。**子时既正，固无所谓夜矣**。」
- 命理取时辰**以气论**：子时固一气，故不分早晚
  （类比中医以子时为胆经所主，未闻胆经有两分之说）。
- 早子时／晚子时之说最早见于民国袁树珊《命理探原》
  （「所谓夜子时，乃今日之夜，非明日之早也」），
  是西学东渐引入 24 小时制后对传统十二时辰的修正，
  **经典古书中没有把它用于论命的记载**。

### 本系统采用的默认口径

**默认按口径 A（日在子正，23:00–23:59 仍属当日）。**

理由：

1. 口径 A 有《新唐书》《渊海子平》《星平大成》三处文献支持，
   且时间跨度从唐到清，比民国才出现的说法更接近命理学的原始形态。
2. **主流黄历采用口径 A 的日界**。用户拿黄历对照日柱时不会以为算错了。
3. 口径 A 在子时内**包含一次日柱更换**，这符合「日在子半」的天文事实。

系统同时提供口径 B 的对照结果，并标注两者差异 ——
这是**唯一**会让四柱整体不同的选择，必须让用户看见。

## 三、默认示例的完整推算（可复算）

以下用**内置默认色板所依据的那一例**演示完整推算（用户可在外观偏好页换成自己的）：

出生：公历 1985-01-27 23:15　吉林市船营区（126.56°E / 43.84°N）

```
真太阳时 = 23:15 + 26.2（经度）+ (−12.3)（均时差）+ 0（夏令时）
         = 23:15 + 14.0 分 = 23:28
```

| 柱 | 结果 | 依据 |
|---|---|---|
| 年柱 | **甲子** | 1985 年立春 1985-02-04 15:25，出生在其前 → 用 1984 年干支，1984 = 甲子 |
| 月柱 | **丁丑** | 处于小寒（1985-01-05 09:33）之后，为丑月；甲年五虎遁「甲己之年丙作首」→ 寅月起丙寅，顺推至丑 → 丁丑 |
| 日柱 | **丙寅** | JDN(1985-01-27) = **2446093**；干支序 = (2446093 + 49) mod 60 = 2 → 丙寅 |
| 时柱 | **戊子** | 真太阳时 23:28 属子时；日在子正口径下仍属**当日**，日干 **丙**，五鼠遁「丙辛从戊起」→ 戊子 |

另一种口径（日在子初，23:00 进次日）：日柱 **丁卯**、时柱 **庚子**。

**核对方式**（三重独立验证）：

| 日期 | 计算结果 | 期望 | 来源 |
|---|---|---|---|
| 1949-10-01 | 甲子 | 甲子 | 内置锚点，JDN 2433191 |
| 1985-01-27 | 丙寅 | 丙寅 | 万年历 |
| 1985-01-28 | 丁卯 | 丁卯 | 万年历（顺推一位，验证连续性） |

五鼠遁十组口诀（甲己→甲、乙庚→丙、丙辛→戊、丁壬→庚、戊癸→壬）亦已逐条验证。

## 四、已更正的错误

`主题配色-八字喜用.md` 初版的四柱推算中有两处错误：

| 项 | 初版 | 更正 | 错因 |
|---|---|---|---|
| 日柱 | 甲子 | **丙寅** | 该文件记 `JDN(1985-01-27) = 2446097`，实际为 **2446093**（差 4 天）；用错 JDN 推出的干支随之错 |
| 时柱 | 甲子 | **戊子** | 随日柱错而错。日干为丙时，五鼠遁「丙辛从戊起」→ 子时为戊子 |

年柱（甲子）与月柱（丁丑）**原推算正确**，无需更正。

### 教训

初版只写了结论（甲子日），没写 JDN 数值是怎么参与运算的，所以错误藏了很久 ——
年柱月柱都对，整体看起来不像有问题的样子。

现在本文第三节把真太阳时公式、JDN 数值、干支序公式、交叉验证锚点
全部写出来了，任何人可以两分钟复算一遍。配套地，
`packages/shared/src/bazi` 的 `computeChart()` 返回 `methodology` 数组，
把每一步的口径与中间值都列出来，界面必须展示（默认折叠）——
**结论和过程一起给，才可能被独立核对**。

## 五、更正后的命局与喜用

日主为**丙火**，不是甲木。

丙火生于丑月（腊月），天寒地冻；年支子、时支子，冬水本旺；
日支寅藏甲木，是全局唯一的生火之源。

| | 五行 | 说明 |
|---|---|---|
| **用神** | **木** | 印星生火。丙火生腊月，非木不生；木又化水，把克火的水转成生火的木 |
| **喜神** | **火** | 比劫助身。木生火、火暖局，日主得助则不畏寒 |
| **闲神** | **土** | 食伤泄火，但土能制水 —— 功过相抵，不作主色 |
| **忌神** | **水** | 官杀克火，且加重寒湿 |
| **忌神** | **金** | 财星耗身，又生水助寒；且金克木，断火之源 |

完整论证见 `主题配色-八字喜用.md` 第一、二节。

## 六、配色映射

五行 → 色相沿用既有约定（见 `主题配色-八字喜用.md` 第三节）：

| 五行 | 色相区间 | 角色 | 用途 |
|---|---|---|---|
| 木 | 70-170° 松绿 | **用神** | **主色** |
| 火 | 0-45° 赤陶 | **喜神** | 辅色、强调 |
| 土 | 45-70° 赭黄 | 闲神 | 极少量点缀（警告 UI 元素） |
| 金 | — | 忌神 | 不用。中性灰阶须为**真灰**，不带冷银 |
| 水 | 170-330° 蓝青 | 忌神 | 不用。借方金额**不得用蓝色** |

三条不可动摇的约束仍然有效：

1. **骨架中性** —— 中性色取近真灰（饱和 ≤8%），界面主体必须「无色」。
   五行意象只放在**点**上，不放在**面**上。
2. **可读性优先** —— 承载文字的色必须过 WCAG AA（≥4.5:1），逐项校验。
3. **忌神色不入 UI** —— 金属性的冷银、水属性的蓝青一律避免。

## 七、实现约束

1. 节气用**太阳视黄经**计算（黄经每 15° 一个节气），不用「世纪常数 + 0.2422×年」查表式。
   后者是手算近似，系数按世纪分段且有例外年份修正，
   记错一个系数就整体偏移一天（本项目实测踩到：1985 年立春被算成 2 月 6 日）。
   黄经法精度实测 **2-7 分钟**，且没有分段与例外表。

2. 农历换算用运行环境内置的中国农历（`Intl` 的 `zh-CN-u-ca-chinese`，
   Node 与浏览器均原生支持，含闰月）。
   **不要自己维护农历数据表** —— 表会过期，内置实现不会。

3. 出生时刻靠近节气或时辰边界时必须**给出警示**，不要假装精确。
   节气计算误差分钟级，真太阳时修正可达 ±1 小时（西部），
   两者叠加足以让边界附近的时辰翻转。
   默认示例真太阳时 23:28，距子时边界 32 分钟 —— 系统会明确标出这个距离。

4. 出生地经度表只到**地级市**（`packages/shared/src/bazi/cities.ts`）。
   同一地级市内经度差通常不足 0.5 度（< 2 分钟），对 120 分钟的时辰无影响；
   再往下精确是把精力花在不影响结论的位数上。
   但「手工填经纬度」的入口必须保留 —— 预置表无论多长都不够用。
