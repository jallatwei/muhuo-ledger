# 00 · 总览与范围

## 1. 这个系统解决什么问题

小企业/个人组织的记账现状：

| 环节 | 现状痛点 | 本系统的做法 |
|---|---|---|
| 收单据 | 纸质发票、电子发票、PDF、微信截图散落各处 | 统一导入（拖拽/文件夹监听/邮箱），原图永久留档 |
| 录账 | 手工敲科目，容易串科目、串税率 | 规则引擎自动出分录，人只做「确认/纠正」 |
| 凭证 | 手工编号、易漏易重 | 系统连续编号 + 借贷平衡硬校验 + 幂等防重 |
| 结账 | 忘了认证发票、忘了结转损益 | 结账前 12 项检查清单，不合格不允许结账 |
| 输出 | 凭证册要手工排版打印 | 一键生成 A4 凭证册 PDF，直接打印装订 |
| 报税 | 对着账本手填申报表 | 由总账余额直接映射生成申报表底稿 |

## 2. 范围（第一版做什么 / 不做什么）

### 做

1. **主体与期间管理**：单个或多个核算主体，会计期间（月）、期间锁。
2. **科目表**：内置《小企业会计准则》科目表，可增删改（末级科目才能记账）。
3. **凭证内核**：手工凭证 + 自动凭证，借贷平衡、期间校验、审核、过账、红冲。
4. **单据管理**：合同（备查）、销项发票、进项发票、银行流水/回单。
5. **识图抽取**：图片/PDF → 结构化字段 → 校验 → 置信度与人工复核。
6. **自动记账规则引擎**：条件 → 分录模板，置信度分级，可自学习（用户纠错沉淀为规则）。
7. **一般纳税人增值税**：专用发票认证、进项税额归集与结转、销项税额、进项税额转出。
8. **月末结账**：检查清单 → 期末结转 → 期间锁定 → 结转下期期初。
9. **报表输出**：凭证册、科目余额表、总账、明细账、资产负债表、利润表、现金流量表。
10. **申报表输出**：增值税主表 + 附列资料一/二 + 附加税费 + 企业所得税预缴表（底稿）。
11. **风险预警**：规则型（确定性）+ AI 型（异常检测）双通道。
12. **AI 适配层**：Provider 可插拔，支持云端多模态模型与本地/离线 Mock。

### 不做（第一版明确排除）

- ✗ 工资薪金与个人所得税全员全额申报（独立模块，后续单开）
- ✗ 电子发票直连开票（税控盘/数电票开具）
- ✗ 与银行 API 直连（第一版靠导入回单/流水 Excel）
- ✗ 多币种折算与汇兑损益
- ✗ 存货计价（先进先出/移动加权）与成本核算
- ✗ 固定资产卡片与折旧（先用手工凭证处理，后续加模块）
- ✗ 合并报表、审计底稿
- ✗ 完整 RBAC 与多租户 SaaS 计费

> 这些不是「没想到」，是**主动切掉**。第一版的目标是「一个人、一个主体、一个月 100~300 张票据，能准确记完并报出税」。

## 3. 三个不可动摇的设计红线

### 红线一：借贷永远平衡

- 金额一律用 `DECIMAL(18,2)` 存储，代码侧用 `Decimal`，**全系统禁止 float/double 参与金额运算**。
- 每条分录 `direction ∈ {DEBIT, CREDIT}` + `amount > 0`（正数约束），不用负数表示方向。
- 凭证落库前在**同一事务内**校验：`SUM(debit) == SUM(credit) AND SUM(debit) > 0`。
- 数据库层用触发器做最后一道防线（防止绕过应用层的写入）。

### 红线二：同一张单据绝不重复入账

- 原始文件按 **SHA-256 内容哈希**去重，重复导入直接返回已存在的单据。
- 发票按**发票代码 + 发票号码**（数电票按 20 位发票号码）做业务唯一键。
- 自动生成凭证时携带 `idempotency_key`（如 `INV:{invoiceId}:v1`），数据库唯一索引兜底。
- 重试、断点续跑、用户重复点击，都不会产生第二张凭证。

### 红线三：已结账的账，改不动

- 过账前校验会计期间状态：`OPEN` 才允许写入。
- 数据库触发器拒绝向已 `CLOSED` 期间插入或修改凭证。
- 要改？走 **反结账 → 红冲 → 重新结账** 的显式路径，每一步留痕。

## 4. 角色与使用方式

第一版只有两种角色，不做复杂权限矩阵：

| 角色 | 能做什么 |
|---|---|
| `OWNER`（老板/会计本人） | 全部操作，含结账、反结账、规则配置 |
| `OPERATOR`（助理） | 导入单据、复核凭证，**不能**过账与结账 |

## 5. 关键术语统一

| 术语 | 含义 | 备注 |
|---|---|---|
| 单据（Document） | 用户导入的原始文件（图片/PDF/Excel） | 只存不改 |
| 票据（Voucher 业务含义） | 从单据抽取出的业务对象：发票/回单/合同 | 有结构化字段 |
| 记账凭证（JournalVoucher） | 会计凭证，含分录行 | 会计意义上的"凭证" |
| 分录（JournalLine） | 凭证中的一行：科目 + 方向 + 金额 | 借贷方各至少一行 |
| 期间（Period） | 会计期间，本系统为「月」 | 状态：OPEN/CLOSED |
| 税期（TaxPeriod） | 纳税申报期，季报时 = 3 个会计月 | 与期间解耦，用关联表表达 |
| 过账（Post） | 凭证从草稿变为正式入账 | 过账后才影响余额 |
| 红冲（Reverse） | 生成一张反向凭证冲销原凭证 | 不物理删除 |

> ⚠️ 注意区分「票据」和「凭证」：一张发票是**票据**，它触发系统生成一张**记账凭证**。中间那层转换就是「自动记账」。
